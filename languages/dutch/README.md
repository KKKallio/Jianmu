# Nederlands · Dutch branch of Jianmu

This branch contains daily Dutch lessons, progressing from A1+ to A2 civic integration and KNM (target March 2027), then B1 and NT2 Staatsexamen Programma II B2 (target end of 2027).

Open [the Dutch homepage](index.html) to navigate lessons.

Each lesson is standalone HTML. Quiz answers and activity progress are stored in browser localStorage, not transmitted to GitHub. Original listening transcripts are independent from third-party audio resources. The GitHub Pages site can be published from the repository main branch root, at https://kkkallio.github.io/Jianmu/.

Jianmu is a learning world tree: languages and subjects form branches, lessons form leaves.
