2. 语法 · Grammar

1
Persoonlijke voornaamwoorden als object
宾语代词

宾语代词表示动作的接受者。 Object pronouns identify who receives an action.

ik → me/mij · jij → je/jou · hij → hem · zij → haar · wij → ons · jullie → jullie · zij (plural) → ze/hen

De bezorger belt me.
快递员给我打电话。
The driver calls me.
Ik help haar.
我帮助她。
I help her.
Kun je ons helpen?
你能帮助我们吗？
Can you help us.

2
Eerst, daarna, dan, uiteindelijk
事件顺序

顺序词置于句首时，变位动词仍在第二位置，主语在其后。 A fronted sequencing word is followed by the finite verb, then the subject.

Eerst controleer ik mijn e-mail.
首先我检查邮件。
Daarna ga ik naar het afhaalpunt.
然后我去取件点。
Dan laat ik mijn code zien.
接着我出示取件码。
Uiteindelijk krijg ik mijn pakket.
最后我拿到包裹。

3. 听力 · Listening

注意未成功投递的原因、取件地点、关门时间以及取件所需物品。
Listen for the failed-delivery reason, collection location, closing time and items required for pickup.

Everyday Dutch listening ↗

以下是本课原创快递客服对话，与外部录音并非同一内容。
This original dialogue does not match external audio.

Medewerker: Goedemorgen, klantenservice. Waarmee kan ik u helpen?

Emma: Goedemorgen. Ik verwacht een pakket, maar ik was gisteren niet thuis.

Medewerker: Heeft u een bericht ontvangen?

Emma: Ja, ik heb een melding gekregen. Mijn pakket ligt bij een afhaalpunt.

Medewerker: Heeft u de afhaalcode?

Emma: Ja, de code is 4826.

Medewerker: Een moment, ik controleer het. Uw pakket ligt bij het afhaalpunt aan de Marktstraat.

Emma: Hoe laat sluit het afhaalpunt vandaag?

Medewerker: Vandaag sluit het om vijf uur.

Emma: Moet ik mijn identiteitskaart meenemen?

Medewerker: Ja, neem voor de zekerheid uw identiteitskaart en de afhaalcode mee.

Emma: Prima. Dan haal ik mijn pakket vanmiddag op. Bedankt!

Medewerker: Graag gedaan. Fijne dag!

4. 口语 · Speaking

复述取件电话 · Retell the call

用 4–6 句荷兰语复述 Emma 没有收到包裹的原因、取件地点、关门时间和需要携带的物品。
Retell the delivery problem, location, closing time and required items.

参考回答 · Model answer

Emma verwacht een pakket. Ze was gisteren niet thuis. Haar pakket ligt bij een afhaalpunt aan de Marktstraat. Het sluit om vijf uur. Ze neemt haar identiteitskaart en afhaalcode mee. Vanmiddag haalt ze het pakket op.

模拟取件 · Collect a parcel

在取件点说明你要领取包裹，提供取件码并询问身份证明要求。
Ask to collect a parcel, give your code and ask about identification.

参考对话 · Model dialogue

Klant: Goedemiddag. Ik wil mijn pakket ophalen.
Medewerker: Heeft u een afhaalcode?
Klant: Ja, hier is mijn code. Moet ik mijn identiteitskaart laten zien?
Medewerker: Ja, graag.
Klant: Alstublieft. Bedankt!

Include the notification context, then ask about the collection address, opening hours and identification requirements.

7. 荷兰社会 · Dutch society (KNM)

Pakketbezorging en afhaalpunten · 快递与取件 · Parcels and collection points

在荷兰，未成功投递的包裹可能被送到邻居、取件点或包裹柜，具体以承运商通知为准。取件前检查地址、营业时间、领取期限和身份证明要求。取件码不要随意分享。

An undelivered parcel may be left with a neighbour, sent to a collection point or placed in a parcel locker. Check the carrier's message for the address, opening hours, collection deadline and ID requirements. Keep your collection code private.

Nederlands: Controleer het afhaaladres, de openingstijden en de afhaaltermijn. Neem de afhaalcode en, als dat nodig is, uw identiteitsbewijs mee.
